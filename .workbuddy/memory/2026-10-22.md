## 需求 49：小车B 三站位

### 裁图定位（可复用的量法）
- 裁图 637×166 px，与 `image/handler_top_clean.png` 的 **(622,1101)-(1259,1267)** 同比例
  （3.84 : 1）；用两只大同步轮的圆心间距（照片 176px vs 裁图 ~185px）交叉验证，误差 <5%。
- 换算到画布（1696→1010，S=0.59552）：车体 **x 372..748 / y 604..792**；
  两轮圆心 (500,705)、(605,705)，中间绿皮带 x 540..570。
- 三站位中心 x：**下料位 434 / 测试位 560 / 上料位 686**。
- 与 `Motion/MotionManager.cs:809-832` 的取放剧本对得上：上料臂放料 → 小车→测试位 900mm →
  下料臂取料 → 小车回位；即「小车本身是上料与下料之间的搬运介质」。

### 画法
- 车体只加「极淡底色（alpha 0x33）+ 青绿描边」，照片里的同步轮/绿皮带照常透出来。
- 左右两站位铺 4 列 × 8 行 = 32 格的 n×m 格纹（描边 alpha 0xB4、0.8px）。
- 站位文字放在车体上沿**上方** 16px（`CB_Y0 - 16`），「小车B」放在车体下沿下方 ——
  下料臂的 Y 行程是 `446.4 + beamLiftD`，beamLiftD 最大 +161.9 ⇒ 最低会压到 y≈608..722，
  放在车体内部会被手臂贴图盖住（第一版踩过，截图里「下料位」正好被红滑座压掉）。
- 原「皮带上在途」改成「车上在途」：批次按相位走 上料位→测试位（0.97s）→压测（2.6s，
  芯片转琥珀 + 压头填色）→下料位（0.97s）→顶升移交缓存盘（1.8s）。合计 6.34s。

## 需求 50：满盘上去 / 空位补盘

- 满 32 颗 ⇒ `layerCnt[4]++`（出空盘塔）+ `towerHold[4]=1.2` + 整盘「上飞」1.1s
  （W 缩 10%、H 压到 10px 收进摞里、最后 18% 淡出），出料位 `outHasTray=false` 变空位框。
- 空位期间 `placeD` 直接拦住（芯片留在吸嘴上等盘）—— 真机就是这个背压。
- 搬运臂时隙优先级：**补出料盘 > 需求44 空盘搬运 > 需求45 补塔**。
  关键帧 0.14 到进空盘 / 0.17 抓 / 0.26→0.58 走 / 0.62 放 / 0.68→1.0 回停放位。
- 放盘那一刻 **`outIdx` 才前进到下一个 bin**，所以补盘目标必须**进时隙时锁存**
  （`outTrayBay`）。否则 `outIdx++` 会让 `outBayX` 在回程段突变 77px，手臂被限速器拖出一次可见的甩尾。
- 进空盘塔见底（0 层）时按「人工补一摞空盘」补到 5 层再取，避免长时间演示死锁。

## 顺手修掉的守恒 bug
- 上料臂放加热盘原来是 `heatLoad = Math.Min(176, heatLoad + carryU); carryU = 0;`
  —— 盘满时会**把超出的芯片凭空吞掉**。改成 `heatLoad + carryU <= 176` 才放，放不下就留在吸嘴上。
