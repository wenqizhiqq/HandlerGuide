# 2026-10-22（补）· 需求 51：脚本列表 0 条 + 中间空白

用户截图（1125×1246，150% DPI）问：「为什么中间空白这么多呢，右侧脚本的列表呢，
需要几十个脚本lua的，while循环的啊」。

## 列表 0 条的真实原因
- `Flow/LuaFlowHost.ScriptDir` = `AppContext.BaseDirectory/Scripts`，但 `Scripts/*.lua`
  **只存在于源码目录**，csproj 里没有任何拷贝条目 ⇒ 输出目录下没有 Scripts ⇒ `Scan()` 扫到 0 个
  ⇒ 面板永远显示「流程列表（0 条）」。
- 修复：csproj 加 `<Content Include="Scripts\**\*.lua">` + PreserveNewest。
- 顺带把 27 个 TODO 骨架填成真流程，并补 3 条监测流程，共 **30 条**，每条都是
  `while running() do ... end`；运动类走 `take/give` 令牌，被安全层拒绝会 `alarm(lasterr())`。
- 面板首次进入自动选中第一条（右侧编辑器不再是空白）；流程表内容改为顶对齐
  （`ScrollViewer.VerticalContentAlignment=Top`）——原来标题行会飘到列表中间。

## 中间空白 = 画布列被挤没
- 截图反算：页面内容约 749 DIP 宽（150% DPI 下 1125 px），右栏固定 490 DIP，
  左栏只剩 ≈259 DIP；1010×819 的画布等比缩下来只有 259×210 DIP，那一列本来就会大片留白。
- 截图里左列连缩略图都没有（逐像素扫过，x<388 全是 #F5F5F7 页面底色）⇒ 等比容器被压到 0。
- 兜底：`Element` 加 `MinW/MinH`，Fit 模板绑定 `MinWidth/MinHeight`，俯视图那一个容器给 240×200，
  窄窗口下不会再缩成看不见的一条。**根因没在静态分析里坐实，要跑一次才知道是否消失。**

## 顺手修掉
- `LuaFlowHost.StopAll` 里 `Thread.Abort()` 在 .NET Core 直接抛 `PlatformNotSupportedException`
  （.NET 8 编译期 SYSLIB0006 警告、运行时必炸）→ 改成只记日志。
- `StartAll` 在 `SafeOk=0` 时打一条提示：运动类流程会「让行：未安全」，
  要先去「运动仿真」页点〔流程启动〕把安全扫描线程拉起来。

## 验证
- `dotnet build` 0 警告 0 错误；`bin/Debug/net8.0-windows/Scripts` 里 30 个 .lua。
- 30 个脚本做了结构性检查：`function/if/for/while` 与 `end` 配平、都有 `while running()`。
- **没有启动程序**（用户明确「不要运行」）。
