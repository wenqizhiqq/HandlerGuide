# 2026-10-15 · 需求 45：搬运臂「判断自动盘空了才搬运」

## 需求（用户）
「仿真页面的俯视图的搬运料盘手臂需要判断自动盘空了才搬运过去」

## 实现（LayoutPages.BuildLayoutCanvasTop + Model.cs）
- **判空门控**：slot 2 常规补盘剧本不再每轮必演。进 slot 2 前锁存
  `refilling / refillIdx`：只有自动盘1..3 里最空的塔层数 < `MinTrayAlarmLayers(3)`
  （= 塔内黄旗「需增加料盘」点亮的塔）才演；目标 = 最空塔（平手取靠左），
  三塔都有料 ⇒ 搬运臂整轮停停放位（trayTarget = armRestX，事件分支 `else if (refilling)`）。
- **塔为何会空**：上料位换新盘的供盘方由「进料盘 -1」改为**自动盘三塔轮供**
  （`srcTower` 0→1→2，每次 carry drop 供一盘塔 -1 层；轮到空塔退回进料盘兜底）
  ⇒ 物料闭环：进空盘→(搬运)→自动盘→(皮带)→上料位→(吸空搬运)→出空盘。
- 叠层显示钳位 `<1→1` 改 `<0→0`（塔见底显示「0层」）。
- Model.cs `NewTopTrayLayers`：静态首屏演示报警位从 a[5]（进料盘）改钉 **a[0]**
  （自动盘3 = 2 层）⇒ 演示一启动第一轮就能看到「判空 → 补盘」。
- 补丁脚本：`artifacts/req45_patch.py`（10 处唯一匹配替换，全 assert count==1）。
