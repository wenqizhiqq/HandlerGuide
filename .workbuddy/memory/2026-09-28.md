## 主界面右侧新增「操作按钮面板」（复刻实体操作面板）
- 文件：`ViewModels/HomePages.cs`
  - 新增 `public static Element OperationPanel()`：4 列 × 5 行 = 20 键圆角按钮 + 每键一颗状态 LED。
    - 单元格 = `E.LiveLamp(ledGet, ledRed, false, 11)` + `E.Btn(label, act, "CmdButton", 12, en)` 垂直堆叠，按钮 `HAlign=Stretch` 撑满。
    - 20 键：开始运行(绿)/停止/暂停/复位 · 归零/急停(红)/报警清除/全部停止 · 清机/清出/跳过/重试 · 结盘/出盘/单步/计数清零 · 照明/拆卸/SNAP/保留。
    - 命令接入 `Ops` / `LotOps` / `MotionManager`；可用性 `Enabled = () => Ops.CanXxx` 跟随运行状态自动灰显；LED 用 `LiveLamp` 实时刷新。
  - `MainScreen()` 网格列由 `"460","*","260"` → **`"460","*","260","320"`**，`root.Add(OperationPanel(), col: 3)` 挂到最右列。
- 代码整洁：修掉 34 个 **CS8619** —— `defs` 元组里 `en/bg/fg` 允许 null，把这 3 个字段声明成可空（`Func<bool>?`/`Brush?`），`led` 保持非空。
- 版式：`Element.VAlign` 默认 `Center`，面板内容会在整列里垂直居中、与其它三张顶对齐卡片不齐 → 显式 `panel.VAlign = VerticalAlignment.Top`。
