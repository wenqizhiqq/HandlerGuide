### 调研结论（平移式分选机 = pick & place sorter）
待测盘 → **上料吸嘴阵列整排真空吸取（2×4=8）** → 放到加热盘/测试工位 → 测完一批由
**出料梭/皮带**送出 → **下料吸嘴按 bin 分选**放进对应收料盘 → **满盘由轨道送回料仓、换入空盘**。
料盘侧靠「料盘升降 + 轨道传送」多层机构连续供盘/收盘。

### 改造后的芯片链路（LayoutPages.BuildLayoutCanvasTop 的 Draw）
| 环节 | 状态量 | 触发条件 | 事件日志 |
|---|---|---|---|
| 上料吸嘴取料 | `feedChips -= 8; carryU = 8` | slot 1 + 吸嘴中心对准上料位 | `req48 pickU` |
| 放到加热盘 | `heatLoad += carryU; carryU = 0` | slot 1 + 中心进入画布 x 800..876 | `req48 placeU` |
| 出测一批 | `heatLoad -= 8` → 上皮带 | 每 6s，且皮带有空槽 + 目标缓存盘放得下 | `req48 out-test` |
| 皮带在途 | `beltSlotX -= 110px/s` | 簇中心到达目标缓存盘心 → `trayChips[i] += 8` | `req48 belt` |
| 下料吸嘴取料 | `trayChips[6..8] -= 8; carryD = 8` | slot 0 + 对准 + 盘里 ≥8 颗 | `req48 pickD` |
| 按 bin 放料 | `trayChips[outIdx] += carryD` | slot 0 + 对准当前 bin 盘 | `req48 placeD` |
| 满盘回仓 | `shipped += 32`，`outIdx` 轮转 11→12→13→11 | 出料盘满 32 | `req48 full-out` |
