✨WPF 工控界面复刻｜半导体分选机 EXCEED9000 上位机 UI 原型源码
本项目参考 JHT‑EXCEED9000 高速分选机操作软件截图，使用 WPF (C#) 复刻一套工控上位机界面原型。
完整还原多页胶囊 Tab 标签页布局，包含【温度设定、设定模式、使能设定、电机归零、信息记录、工位统计】六大功能页面。
界面风格参考原版工业软件：浅色业务背景、分组容器、复选框参数配置、数值输入栏、下拉选择、日志表格视图，底部状态栏展示设备实时状态（运行模式、产品品种、温度、压力、当前页面位置）；顶部保留导航菜单栏，保存、召回、权限选择、关闭程序按钮。

👉本套为**界面原型 Demo，不含底层运动控制、设备通讯、数据库业务逻辑**；仅提供 WPF 前端 XAML + 界面 ViewModel，适合工控软件开发前期 UI 原型验证，也可以作为工控 HMI 界面学习参考。
使用.Net Framework8 开发；页面使用自定义胶囊式 Tab 控件（已处理横向滚动溢出裁切问题，标签数量多时支持横向滑动浏览页签）；控件配色模仿原厂软件浅灰白工业风，不花哨，偏向设备工程师实用风格。
适合做半导体分选、测试分选设备上位机前期界面参考，拿到源码后可继续对接固高 / 雷赛运动控制卡、相机视觉业务，在此原型基础上继续开发业务逻辑。
⚠️注意：仅 UI 原型演示 Demo，不是原厂软件，无设备固件，不能直接控制实体机器。
需要的朋友可以直接拍，交付完整 VS 工程源码。
