**需求**：主界面「通讯」里加上 SECS/GEM，使用免费库；新建独立页面 + 真实 HSMS TCP 连接。

**关键 API（v3.1.0，与 v2 的 `PrimaryMessageReceived` 事件式 API 不同，勿混用）**：
- `new SecsGemOptions { DeviceId, IsActive, IpAddress, Port, T3, T5..T8, LinkTestInterval }` → `Options.Create(opts)` 得 `IOptions<T>`
- `new HsmsConnection(IOptions<SecsGemOptions>, ISecsGemLogger)`；`hsms.ConnectionChanged += (s, ConnectionState)`；`hsms.State`；`hsms.Start(ct)`；`DisposeAsync()`
- `new SecsGem(IOptions<SecsGemOptions>, ISecsConnection, ISecsGemLogger)`；`gem.SendAsync(msg)`；`gem.GetPrimaryMessageAsync(ct)` → `IAsyncEnumerable<PrimaryMessageWrapper>`；`wrapper.TryReplyAsync(reply)`
- `new SecsMessage(byte s, byte f, bool replyExpected = true) { Name, SecsItem }`；`Item.L/A/B/U1/U2/U4/Boolean`（`using static Secs4Net.Item;`）
- 被动模式：HsmsConnection 构造函数里就 `Bind+Listen`，端口被占用会在 ctor 抛 SocketException（要 try/catch）

## 测试机通讯：把「测试接口」做成**真实**收发（TTL / GPIB / RS232 / TCP）

**需求**：`测试接口`页原来只是参数表单 + 假应答（`Ops.TestIo_Send` 回显一条 `ACK (0x06)`，`TestIoRx` 是写死的字符串）。用户要求**真实**测试机通讯。
**澄清结果**：四种接口全要；TCP 由本机作**客户端**主动连测试机；暂时无真机，先按标准实现 + 本机回环自测。

**新增 `ViewModels/TestInterfaceService.cs`（~640 行）** —— 静态服务 + 4 个真实传输实现：
- 接口 `ITransport { string Info; void Open(Action<byte[]> onRx, Action<ITransport> onClosed); void Send(byte[]); void Close(); }`
- `TcpTransport`：`TcpClient`（客户端，`ConnectAsync().Wait(timeout)`）/ `TcpListener`（服务端，`AcceptTcpClientAsync().Wait(timeout)`）；后台读线程 `NetworkStream.Read`。
- `SerialTransport`：`System.IO.Ports.SerialPort`（需 NuGet `System.IO.Ports` 8.0.0），读线程靠 `ReadTimeout` 抛 `TimeoutException` 做空转。
- `TtlTransport`：走运控卡 DIO —— SOT 出（`MotionManager.WriteOut`，40ms 脉冲）、EOT/DUT 入（`ReadIn` 20ms 轮询，跳变才上报）。
- `GpibTransport`：**VISA 优先**（`visa32.dll`：`viOpenDefaultRM/viOpen/viSetAttribute(VI_ATTR_TMO_VALUE=0x3FFF001A)/viWrite/viRead/viClose`），失败**退回 NI-488.2**（`gpib-32.dll`：`ibdev/ibwrt/ibrd/ThreadIbcntl/ibonl`）；两者都缺 → 明确报错让用户装 NI-VISA / Keysight IO Libraries / NI-488.2。
- 状态：`IsConnected / StateText / CountText / LastRx / LogText`（环形 400 行，带版本号缓存；**LiveElement 的 `Set` 用 `EqualityComparer` 值比较，所以新字符串同内容不会触发刷新**）。
- 连接在后台线程建立（TCP 服务端会阻塞到超时），跨线程回调统一 `Post()` 到 `Application.Current.Dispatcher`——**`MachineModel.Logs` 是 ObservableCollection，后台线程直接 `Ops.Info` 会抛跨线程异常**。
- 连接参数（模型键，随 params.json 持久化）：`ti_ip`(127.0.0.1) `ti_port`(5001) `ti_role`(0=客户端/1=服务端) `ti_com`(串口名，取自 `SerialPort.GetPortNames()` 补 COM1~8) `ti_delim`(0=CR+LF/1=CR/2=LF/3=无) `ti_sotbit`(0) `ti_eotbit`(1) `ti_dutbit`(2)；沿用原有 `ti_gpib/ti_baud/ti_data/ti_stop/ti_parity/ti_timeout`。
