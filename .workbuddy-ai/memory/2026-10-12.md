## 需求 32 — 主动保存 / 载入「用户最后一次显示的页面」

**用户原话**：「而且需要主动保存载入用户最后一次显示的页面，导航栏的按钮」

即：切页时自动记住当前页，下次开机直接回到那一页，导航栏（命令中心工具条）上对应的
按钮 / 下拉项高亮也跟着还原。

### 落盘位置与格式

- **新文件 `%APPDATA%\HandlerGuide\ui.json`**（与 `Ops.ParamsPath` 同目录），内容：
  ```json
  {
    "LastPage": "motion_layout"
  }
  ```
- **为什么不塞进 params.json**（写在 `UiState` 的类注释里）：
  1. params.json 是「机器参数」，只有用户按「保存 / 召回」才动它；页面停留位置是界面状态，
     跟着导航一路写 —— 混在一起会让「召回参数」把当前页面也一起拽回去；
  2. params.json 每次写要序列化全部四个参数字典，而切页很频繁；ui.json 只有几个字段；
  3. 参数文件写坏不该连「开机停在哪个页面」也一起丢。
- 已用一次性 net8.0 控制台工程实测 `System.Text.Json` 的往返（默认选项）：
  写入 `{"LastPage":"motion_layout"}`、回读一致；`{}`（旧文件缺字段）→ `null`（被 `?? ""` 兜住）；
  坏 JSON → `JsonException`（被 catch，回默认页面）。默认选项属性名大小写敏感，因为读写同参所以没问题。

### 代码改动

1. **新增 `ViewModels/UiState.cs`**（138 行，无 BOM + CRLF，与同目录其它 .cs 一致）：
   - `public static class UiState` + `public sealed class Snapshot { string LastPage }`；
   - `FilePath => Path.Combine(Ops.DataDir, "ui.json")`；
   - `LastPageId` 属性：get 懒加载，**set 时值没变直接 return 不写盘** ——
     开机恢复会用同一个 Id 再导航一次，那趟不该多写一次盘；
   - 读写全部 try/catch 吞掉（无权限 / 文件损坏都不拦住开机），只在日志留一条。
   - 结构里留了扩展余地：以后记窗口尺寸、上次展开的工具组，往 `Snapshot` 加属性即可，
     旧文件缺字段自动取默认值，不用做版本迁移。
2. **`ViewModels/MainViewModel.cs`**：
   - `Navigate(page)` 末尾加 `UiState.LastPageId = page.Id;` ——
     放在这里而不是各处命令里，因为 `GoHomeCommand / ManualCommand / SecsGemCommand`

     查到就导航过去，查不到（版本升级删页 / 改 Id）就退回主界面**并写一条日志**，
     免得用户以为「记忆功能坏了」。

   `Close()`，再 `Navigate` 会去构建页面内容，平白扰动后面的检查。
