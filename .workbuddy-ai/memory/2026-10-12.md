## 需求 32 — 主动保存 / 载入「用户最后一次显示的页面」

**用户原话**：「而且需要主动保存载入用户最后一次显示的页面，导航栏的按钮」

即：切页时自动记住当前页，下次开机直接回到那一页，导航栏（命令中心工具条）上对应的
按钮 / 下拉项高亮也跟着还原。

### 落盘位置与格式

- **新文件 `%APPDATA%\HandlerGuide\ui.json`**（与 `Ops.ParamsPath` 同目录），内容：
  ```json
  {
    "LastPage": "motion_layout"
  }
  ```
- **为什么不塞进 params.json**（写在 `UiState` 的类注释里）：
  1. params.json 是「机器参数」，只有用户按「保存 / 召回」才动它；页面停留位置是界面状态，
     跟着导航一路写 —— 混在一起会让「召回参数」把当前页面也一起拽回去；
  2. params.json 每次写要序列化全部四个参数字典，而切页很频繁；ui.json 只有几个字段；
  3. 参数文件写坏不该连「开机停在哪个页面」也一起丢。
- 已用一次性 net8.0 控制台工程实测 `System.Text.Json` 的往返（默认选项）：
  写入 `{"LastPage":"motion_layout"}`、回读一致；`{}`（旧文件缺字段）→ `null`（被 `?? ""` 兜住）；
  坏 JSON → `JsonException`（被 catch，回默认页面）。默认选项属性名大小写敏感，因为读写同参所以没问题。
